# 术语表

用于快速确认当前课程中的概念边界。完整原理回对应课程页。

| 术语 | 当前课程中的含义 |
|---|---|
| Host | 执行编译工作的开发机，如 x86-64 Linux |
| Target | 最终运行程序的目标，如 STM32F446ZE / Cortex-M4 |
| Bare Metal | 不依赖常规操作系统的裸机运行环境 |
| Cross Compile | 在 Host 上生成给另一架构 Target 运行的程序 |
| Toolchain | 编译、汇编、链接、二进制分析工具集合 |
| ABI | 函数调用、寄存器使用、数据布局等二进制接口约定 |
| CMake | 构建系统生成器，读取工程描述并生成实际规则 |
| Ninja | 执行构建规则/DAG 的构建工具 |
| CMake Target | CMake 构建图中的逻辑目标，如 executable/library/interface library |
| INTERFACE target | 主要传播 usage requirements，可不产生实际二进制库 |
| PRIVATE | requirement 仅当前 target 使用 |
| PUBLIC | 当前 target 和其使用者都需要 |
| INTERFACE | 主要由 target 的使用者继承 |
| CMSIS | ARM Cortex-M 相关的软件接口规范和组件体系 |
| CMSIS-Core | Cortex-M 核心寄存器、NVIC、SysTick、intrinsics 等访问层 |
| Device Header | 厂商对具体 MCU 外设寄存器、地址、IRQ 的 C 定义 |
| HAL | 厂商提供的较高层硬件抽象接口 |
| LL | 厂商提供的更接近寄存器的 Low-Layer 接口 |
| Platform | 本仓库对目标 MCU/板卡公共构建与运行基础的统一描述 |
| Experiment | 为验证一个具体机制建立的实验单元 |
| Project | 将多个已经验证的能力组合成完整系统 |
| Startup | 向量表、Reset_Handler 及进入 `main()` 前的低级初始化 |
| Vector Table | 保存初始 MSP 和各异常/中断入口地址的表 |
| Reset Vector | 向量表中的复位入口项 |
| MSP | Main Stack Pointer，复位后默认主栈指针 |
| PSP | Process Stack Pointer，可用于线程模式等场景 |
| Linker | 合并目标文件、解析 symbol、安排最终地址并生成 ELF 的工具 |
| Linker Script | 描述 MEMORY、SECTIONS、地址和 linker symbols 的脚本 |
| Input Section | 某个 `.o` 中的 `.text/.data/.bss` 等 section |
| Output Section | Linker 合并 input sections 后形成的最终 ELF section |
| Location Counter `.` | Linker Script 中表示当前输出地址位置的计数器 |
| Linker Symbol | Linker 创建的名字→数值/地址，不是普通 C 对象 |
| Relocation | Linker 用最终地址修正目标文件中引用的机制 |
| Section | 编译/链接时组织代码和数据的逻辑区域 |
| Segment | ELF 从装载视角描述的一组区域 |
| `.text` | 主要保存机器指令 |
| `.rodata` | 主要保存只读数据 |
| `.data` | 非零初值可写静态存储对象常见所在区 |
| `.bss` | 零初值/未显式初始化静态存储对象常见所在区 |
| VMA | Section 运行时使用的地址 |
| LMA | Section 初始镜像被加载/保存的地址 |
| ELF | 包含代码、section、symbol、地址等信息的可执行/链接格式 |
| BIN | 近似原始固件 byte image |
| Intel HEX | 文本形式保存地址、数据、校验信息的固件格式 |
| Symbol | 程序中的名字及其地址/属性信息 |
| Weak Symbol | 可被同名强定义覆盖的弱符号 |
| Flash | 非易失存储，主要保存固件代码和初始数据 |
| SRAM | 易失运行内存，保存变量、栈等 |
| Stack | 函数调用、自动变量、异常现场等常用的 LIFO 运行内存 |
| Heap | 动态内存分配区域，是否使用取决于程序/runtime |
| `SystemInit()` | STM32 系统级初始化入口，具体行为必须看当前源码 |
| `SystemCoreClock` | 软件维护的核心时钟频率变量，不等于硬件自动真值 |
| `HSE_VALUE` | 软件描述 HSE 输入频率的常量，本身不切换系统时钟 |
| HSI | STM32 内部高速时钟；当前早期实验按默认 16 MHz 理解 |
| HSE | 外部高速时钟输入/振荡器路径 |
| PLL | 锁相环，用于生成更高或特定系统时钟 |
| RCC | STM32 Reset and Clock Control 外设 |
| NVIC | Cortex-M Nested Vectored Interrupt Controller |
| SysTick | Cortex-M 内置系统定时器 |
| SWD | Serial Wire Debug，两线调试接口 |
| GDB | GNU Debugger，可查看/控制 MCU 运行状态 |
| OpenOCD | 常见开源调试/烧录服务器，可连接 GDB 与硬件探针 |
