# 补充包安装说明

这些 ZIP 都以 Obsidian 仓库根目录为相对根。

建议顺序：

```text
1. 保留你当前仓库备份 / Git commit
2. 解压补充包 01
3. 解压补充包 02
4. 解压补充包 03
5. 解压补充包 04
6. 解压补充包 05
7. 最后解压补充包 00（主课程链接补丁）
```

01～05 主要是新增文件，不应该覆盖你现有主课程。

00 会覆盖：

```text
README.md
00_课程索引.md
01_P0_仓库与构建基线/01~09
```

它的目的只是在现有课程页顶部增加“深挖入口”，正文仍以当前整理版为基础。

如果你在 00 包生成后又手工改过这些主课程文件，不要直接覆盖；可以只复制其中的 callout 链接段。

---

## Git 建议

安装前：

```bash
git add .
git commit -m "backup notes before fundamentals expansion"
```

安装后检查：

```bash
git status
git diff
```

确认没有意外删除自己的内容再提交。

---

## Obsidian 使用方式

不要从 `10_基础知识体系` 第一篇一路读到最后。

正确：

```text
00_课程索引
→ 课程页
→ 遇到不懂
→ `深入知识页`
→ 如仍不懂继续点
→ 理解后 Back
→ 回主课程
```
