## 上图的四种“世界”

### 构建世界

```text
CMake / compiler / assembler / linker / ELF
```

运行在 PC。

### 存储世界

```text
Flash / SRAM / MMIO
```

存在于 MCU 地址空间。

### CPU 世界

```text
PC / SP / LR / vector / exception
```

Cortex-M 硬件执行。

### 应用世界

```text
RCC / GPIO / Timer / DMA ...
```

你的实验目标。

P0 的意义就是把前三个世界接好，让后续应用实验有可靠地基。
