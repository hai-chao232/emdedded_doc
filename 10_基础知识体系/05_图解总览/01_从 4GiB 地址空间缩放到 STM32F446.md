# 从 4 GiB 地址空间缩放到 STM32F446

## 第 1 层：CPU 能表达的地址编号

Cortex-M4 使用 32-bit address：

```text
0x00000000
│
│  2^32 个 byte address
│
0xFFFFFFFF
```

这叫：

```text
4 GiB address space
```

不代表芯片有 4 GiB RAM。

# 第 2 层：按功能区域粗分

仅作架构级心智图，不要求背所有边界：

```text
0x00000000
┌────────────────────────────┐
│ Code / boot region         │
│                            │
├────────────────────────────┤
│ SRAM region                │
│  常见从 0x20000000 开始     │
├────────────────────────────┤
│ Peripheral region          │
│  常见从 0x40000000 开始     │
├────────────────────────────┤
│ External memory/device     │
│                            │
├────────────────────────────┤
│ ...                        │
├────────────────────────────┤
│ System / PPB               │
│  常见 0xE000....            │
└────────────────────────────┘
0xFFFFFFFF
```

# 第 3 层：当前 STM32F446ZE 最重要的物理资源

## Main Flash

```text
0x08000000
┌──────────────────────────────┐
│                              │
│          512 KiB             │
│                              │
└──────────────────────────────┘
0x08080000  ← end boundary
```

## SRAM

```text
0x20000000
┌──────────────────────────────┐
│                              │
│          128 KiB             │
│                              │
└──────────────────────────────┘
0x20020000  ← end boundary
```

# 第 4 层：Peripheral

外设不一定有“单独 RAM”。

它们通过 MMIO 占用地址：

```text
0x400.....
┌──────────────────────────────┐
│ RCC registers                │
├──────────────────────────────┤
│ GPIO registers               │
├──────────────────────────────┤
│ TIM / USART / SPI / ...      │
└──────────────────────────────┘
```

CPU 对这里 load/store，真实硬件状态发生变化。

---

# 第 5 层：Cortex-M System

例如：

```text
0xE000....
┌──────────────────────────────┐
│ NVIC                         │
│ SCB                          │
│ SysTick                      │
│ Debug components             │
└──────────────────────────────┘
```

这就是为什么：

```text
GPIOB
```

主要属于 ST MCU 外设，

而：

```text
NVIC / SCB->VTOR
```

主要属于 Cortex-M 内核系统组件。

# 启动时为什么又出现 0x00000000？

STM32 boot mapping：

```text
Reset CPU fetch
0x00000000
    │
    │ normal Main Flash boot 时 alias
    ▼
Main Flash
0x08000000
```

所以不要把：

```text
0x00000000
```

和：

```text
0x08000000
```

简单理解成“两份相同 Flash”。

是启动映射关系。
