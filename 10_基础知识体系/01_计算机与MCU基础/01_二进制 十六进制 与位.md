# 二进制、十六进制与位

## 一句话先说清

CPU 最终处理的是一串位。嵌入式里大量使用十六进制，只是因为它能更紧凑地表示二进制，而且每一位十六进制数字刚好对应 4 个二进制位。

---

## 1. bit 是什么？

bit 只有两种状态：

```text
0
1
```

8 个 bit 组成 1 Byte：

```text
b7 b6 b5 b4 b3 b2 b1 b0
```

例如：

```text
1010 0110
```

这是一个 8 bit 数。

---

## 2. 为什么嵌入式里到处是十六进制？

直接写 32 bit 二进制：

```text
0010 0000 0000 0000 0000 0000 0000 0000
```

很难读。

换成十六进制：

```text
0x20000000
```

立刻短很多。

因为：

```text
1 个 hex digit = 4 bit
```

映射：

```text
0 = 0000
1 = 0001
...
9 = 1001
A = 1010
B = 1011
C = 1100
D = 1101
E = 1110
F = 1111
```

所以：

```text
0x2A
= 0010 1010
```

---

## 3. 32 位数为什么常写 8 个十六进制数字？

因为：

```text
8 hex digits × 4 bits = 32 bits
```

所以一个 32 bit 地址常写：

```text
0x08000000
0x20000000
0x40000000
```

这也让地址的高位区域很容易看出来。

---

## 4. bit position 和 bit value

例如寄存器：

```text
0000 0000 0000 0100
```

只有 bit2 为 1。

因为最低位是 bit0：

```text
bit7 bit6 bit5 bit4 bit3 bit2 bit1 bit0
 0    0    0    0    0    1    0    0
```

所以：

```c
1U << 2
```

得到：

```text
0b00000100
= 0x04
```

---

## 5. 为什么寄存器配置经常用移位？

假设 GPIO 某字段占 bit[5:4]：

```text
00 input
01 output
10 alternate
11 analog
```

如果要写 `01` 到 bit[5:4]：

```c
1U << 4
```

得到：

```text
0001 0000
```

也就是把 1 放到 bit4。

如果字段值是 `2`：

```c
2U << 4
```

二进制：

```text
2 = 10
10 << 4
= 0010 0000
```

---

## 6. mask 是什么？

mask 就是一组“我关心哪些 bit”的位模式。

例如：

```c
0x3U << 4
```

因为：

```text
0x3 = 11
```

左移 4：

```text
0011 0000
```

表示：

> 我关心 bit4 和 bit5。

清除这两位：

```c
reg &= ~(0x3U << 4);
```

然后写新值：

```c
reg |= (0x1U << 4);
```

---

## 7. `| & ^ ~` 在寄存器里为什么常见？

### OR `|`

把某些位设为 1：

```text
x | mask
```

### AND `&`

保留 mask 为 1 的位：

```text
x & mask
```

### NOT `~`

逐位取反。

### XOR `^`

不同为 1，相同为 0，常用于翻转位。

---

## 8. “设置一个 bit”不等于“给寄存器赋值 1”

假设寄存器当前：

```text
1010 0000
```

你想把 bit0 设为 1。

如果：

```c
reg = 1;
```

结果：

```text
0000 0001
```

其他位全被破坏。

如果：

```c
reg |= 1U;
```

结果：

```text
1010 0001
```

这就是读-改-写。

但注意：某些硬件寄存器不适合 read-modify-write，所以 STM32 GPIO 有 `BSRR` 这种原子置位/复位寄存器。后面 001 会看到。

---

## 9. 十六进制地址的差值就是字节差

例如：

```text
0x20000000
0x20000004
```

差：

```text
4
```

表示相差 4 Bytes。

若一个 `uint32_t` 占 4 Bytes，那么两个连续 32 bit word 地址通常相差 4。

---

## 10. 一个 32 位寄存器为什么常有 bit31..bit0？

32 bit：

```text
31                 16 15                  0
┌────────────────────┬────────────────────┐
│                    │                    │
└────────────────────┴────────────────────┘
```

每一位都可能被硬件赋予特定含义。

Reference Manual 中的寄存器图，本质上就是告诉你：

> 这 32 个 bit 分别代表什么。

---

## 11. 常见误区

### 误区：`0x10` 是十

不是。

```text
0x10 = 16
```

### 误区：bit1 是第一个 bit

通常最低位叫 bit0。

### 误区：十六进制是 CPU 直接“理解”的格式

CPU 只处理位模式。十六进制主要是给人看的表示法。
