# 3. 正确使用方法：不要按百科全书顺序硬读

你仍然以：

[[00_课程索引]]

为主。

例如读到：

```text
Cortex-M 从向量表读取初始 MSP
```

如果“向量表”不懂：

```text
课程页
  ↓ click
[[10_基础知识体系/03_Cortex-M与启动中断/04_向量表 Vector Table]]
  ↓
看懂到足以继续
  ↓ back
课程页
```

如果向量表页里又不懂“地址空间”：

```text
Vector Table
  ↓
[[10_基础知识体系/01_计算机与MCU基础/04_地址 地址空间 与内存映射]]
  ↓ back
Vector Table
  ↓ back
Startup 课程
```

这就是 Obsidian 最适合你的地方：

> **深度可以无限追，但主线不需要无限变长。**

# 4. 三种“完成”不要混

## 看懂

读完能跟着解释。

## 闭卷复述

不看笔记能自己讲因果链。

## 实证

能从：

```text
source
ELF
debugger
hardware
```

找到证据。

对于核心 P0 概念，最终目标是第三种。

# 5. 目前最重要的总链

```text
C / ASM
  ↓
preprocess / compile / assemble
  ↓
Object Files
  ↓
Linker + Linker Script
  ↓
ELF
  ↓
Flash
  ↓
Reset
  ↓
Vector Table
  ├─ Initial MSP
  └─ Reset_Handler
  ↓
Startup
  ├─ SystemInit
  ├─ .data copy
  ├─ .bss clear
  └─ runtime init
  ↓
main
  ↓
001 GPIO
```

只要这条链还没在脑子里稳定，就不要担心“进度慢”。

它是后面所有外设实验的底层地基。
