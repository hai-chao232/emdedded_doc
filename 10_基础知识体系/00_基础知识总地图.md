# 5. 目前最重要的总链

```text
C / ASM
  ↓
preprocess / compile / assemble
  ↓
Object Files
  ↓
Linker + Linker Script
  ↓
ELF
  ├─ ELF Header
  ├─ Section Header Table
  └─ Program Header Table
  ↓
Flash
  ↓
Reset
  ↓
Vector Table
  ├─ Initial MSP
  └─ Reset_Handler（入口值可能带 Thumb bit）
  ↓
Startup
  ├─ SystemInit
  ├─ .data copy
  ├─ .bss clear
  └─ runtime init（__libc_init_array → .init_array）
  ↓
main
  ↓
001 GPIO
```

只要这条链还没在脑子里稳定，就不要担心“进度慢”。

它是后面所有外设实验的底层地基。
